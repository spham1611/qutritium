# `legacy/` — historical record of Qutritium v0.0.x

This directory preserves the **pulse-coupled, IBM-quantum-hardware-specific**
code from the v0.0.x line of Qutritium as a historical artefact. None of the
code here is part of the installable v2.0.0 package; it is **not** discovered
by `pip install`, **not** importable as `qutritium.*`, and **not** included
in the wheel.

## Why preserve it?

The v0.0.1 codebase was the deliverable for:

- The **Unitary Fund microgrant** that funded the project.
- The **Munich Quantum Software Conference 2023** poster presentation.

Deleting it outright would erase the historical record of that work. Keeping
it under `legacy/` lets the v2.0.0 refactor proceed with a clean, narrow,
hardware-agnostic API while still letting future readers (PhD application
reviewers, citation chasers, or Son's future self) trace what was done in
2023.

## What's *not* here

The retained, hardware-agnostic core lives in `src/qutritium/`:

- `quantumcircuit/` — gates, instructions, circuit container
- `vm_backend/` — statevector simulator
- `decomposition/` — SU(3) decomposition (with `Pulse_Wrapper` removed)

## Importability

Code under `legacy/` uses the v0.0.1 import paths (`from src.X import Y`)
and depends on `qiskit-ibm-provider`, `qiskit-pulse`, etc. None of these
are runtime dependencies of v2.0.0. **Do not expect the legacy code to
import or run as-is** — it requires the v0.0.1 dependency stack and a
working IBM Quantum account.

If you genuinely need to revive part of it, the suggested path is to:

1. Create a separate Python virtualenv pinned to the v0.0.1 dependency
   versions (see `legacy/old_requirements.txt` if it exists, or check the
   git history at the v0.0.1 tag).
2. Copy the relevant `legacy/*.py` file(s) back into a `src/` tree,
   matching the v0.0.1 layout.
3. Restore the v0.0.1 `pyproject.toml` from git history.

## Why the empty stubs are kept

`benchmarking/` and `clifford/` were placeholder package directories in
v0.0.1 (only `__init__.py`, no actual code). They are preserved here for
completeness of the historical record — if someone wonders "what was
qutritium going to ship next?", these directories answer "Clifford-group
analysis and randomised benchmarking, neither of which was implemented".
